# 链记 · 本地双链笔记与间隔复习

> 每日笔记、`[[双链]]`、反向链接、标签、图谱、间隔复习、Markdown 编辑与预览、全文搜索，全部跑在你的浏览器里。
> 纯前端 · 打开即用 · 无账号 · 无 API Key · 数据不上传 · 完全免费（无 Pro、无授权码、无数量限制）。

在线使用：<https://yguodong627-star.github.io/vibe-shuanglian/>（备注：github.io 会跳转到 ysdtn.com 的对应路径）

## 谁会用、什么场景
- **主要用户**：想用双向链接做个人知识库、但不想装 Obsidian/注册 Notion 的人——学生、产品经理、研究者、写作者；也适合手机上随手记、电脑上整理。
- **场景**：每天写一条日记，把读书/会议/想法用 `[[ ]]` 连起来；周末看图谱和反向链接，发现关联；把要记住的结论加入复习清单。
- **解决的问题**：普通笔记软件没有反向链接，Obsidian 类工具需要安装且手机体验重，在线笔记要账号并把内容放在别人服务器。这里打开网页就能用，数据在本机，随时导出成标准 Markdown 文件夹。

## 功能
- **每日笔记**：“今日笔记”一键创建/打开当天（标题 `YYYY-MM-DD`，带模板，重复点击不会重复创建）。
- **双链**：输入 `[[` 弹出补全；支持 `[[标题|显示文字]]`、`[[标题#小节]]`；预览里点击已存在的链接跳转，点击“未创建”的链接会新建。
- **反向链接面板**：显示谁链接了本篇（带所在行的上下文）、本篇的出链与未创建的链接、**未链接的提及**（正文提到标题但没加 `[[ ]]`）。
- **改名同步**：改标题时可选择把其他笔记里的 `[[旧标题]]` 一并改写。
- **标签**：正文里写 `#标签`；侧栏标签栏、`#标签` 搜索、点击标签筛选。
- **图谱**（Canvas 自绘，无依赖）：链接图谱 / 标签图谱；拖拽节点、平移、滚轮与双指缩放、悬停高亮邻居、点击打开；可只看当前笔记附近、可显示未创建链接。
- **间隔复习**：笔记右栏“加入复习”；复习页先回忆→翻开答案→打分（忘了/模糊/记得/简单）。`==挖空==` 会在复习时被遮住变成填空卡。**调度规则公开**（见下）。
- **Markdown 编辑 + 预览**：分栏/仅编辑/仅预览（手机分页）；工具栏、待办在预览里可直接勾选、自动保存。
- **全文搜索**：标题/正文/标签，多个词 AND，结果带高亮片段，`Ctrl+K` 聚焦。
- **导出/导入**：Markdown 文件夹 ZIP（每篇一个 .md，含 front matter，日记放“日记/”，`[[双链]]` 原样保留，可被 Obsidian 等打开）；JSON 完整备份（含复习进度）；导入支持 JSON、多个 .md/.txt、含 .md 的 ZIP，重名且内容不同的改名为“标题 (导入)”，不会覆盖现有笔记。

### 复习规则（SM-2 简化版）
| 操作 | 效果 |
|---|---|
| 新加入 | 当天到期 |
| 忘了 | 次数归零，明天再看，熟悉度 −0.20（最低 1.30），本次会话稍后再出现一次 |
| 模糊 | 间隔 ×1.2（至少 1 天），熟悉度 −0.15 |
| 记得 | 第 1 次→1 天；第 2 次→3 天；之后 间隔×熟悉度（初始 2.30） |
| 简单 | 第 1 次→3 天；第 2 次→7 天；之后 间隔×熟悉度×1.3，熟悉度 +0.15 |
| 上限 | 单次间隔最长 365 天，按本机日期计算 |

## 已知限制
- 数据在浏览器 IndexedDB：清理站点数据、隐私模式、换设备会丢，**请定期导出**。多个标签页同时编辑同一篇没有冲突合并，后保存的覆盖先保存的。
- 双链按“标题精确匹配（忽略大小写）”，标题不能含 `[ ] | #`；`[[标题#小节]]` 的小节只显示不跳转；没有别名（aliases）与块引用。
- Markdown 是自写的轻量渲染：支持标题、粗斜体、删除线、代码、引用、嵌套列表、待办、表格、分割线、链接。**不支持**图片、脚注、数学公式、Mermaid；原始 HTML 一律转义显示（为了安全）。
- 图谱布局是示意性的；几百篇流畅，上千篇会变慢。
- 复习是 SM-2 简化版，没有学习阶段、没有按分钟重学，也不是 FSRS。
- 手机上 `[[` 补全列表固定在编辑区底部，不跟随光标；补全仅在模拟触屏下测过，未在真实手机输入法上验证。
- 导入 Markdown 时只识别 front matter 里的 `title/created/updated`，其他字段忽略；Obsidian 的 `![[嵌入]]`、`> [!callout]` 不会特殊处理。
- 没有云同步；跨设备请用导出/导入。

## 技术
纯 HTML/CSS/JS，无构建、无第三方运行时库（`vendor/` 里只有本地字体：Instrument Serif、Inter，SIL OFL 1.1；中文回退系统宋体/苹方/微软雅黑）。`md.js`（渲染与提取，可在 Node 里 require）、`sched.js`（复习调度）、`graph.js`（图谱）、`zip.js`（ZIP 读写）、`app.js`。

设计参考 ysdtn.com：纸色 #f0efe9 + 深海军蓝 #00304a/#071a22/#102a36，衬线标题 + 胶囊按钮 + 细线分隔，深色侧栏/右栏与纸色编辑区搭配。Obsidian、Logseq 等只借鉴思路，未复制代码。
